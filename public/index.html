socketsubDocs

Push notifications for RSS and Atom feeds over a WebSocket. Send a list of feed URLs, and socketsub tells you when any of them changes, using rssCloud or WebSub behind the scenes.

WebSocket URL: {{wsUrl}}

To try it, paste a JSON array of feed URLs into the box below and press Send. Each send adds to the feeds this page follows. 

["http://scripting.com/rss.xml"]

If the connection drops, the viewer reconnects on its own, but the new connection follows no feeds. Send the list again.
